# Welcome

This is the documentation for the **inv-fpinn** project — inverse modelling of fractional-order systems using Physics-Informed Neural Networks (PINNs). Semester 7 mini project.

Goal: recover fractional-order parameters (alpha, tau) of a fractional single-degree-of-freedom (SDOF) oscillator from noisy displacement observations.
